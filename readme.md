# NisheshChauhan_Task(21) - OmniFood Landing Page

This project is a modern, responsive food delivery landing page inspired by the OmniFood concept. The primary objective was to build a polished, single-page marketing website for a healthy meal subscription service. The development process focused heavily on implementing a clean UI design system, ensuring an intuitive user layout, and configuring smooth scrolling interactions across the page.

## Overview

The project models a premium food delivery brand featuring an engaging hero section, service highlights, a meal gallery, city information, customer testimonials, pricing plans, and a contact form. It is built as a static front-end application with a focus on professional presentation and complete mobile responsiveness.

## Features

- Full-width hero section with distinct branding
- Healthy food / delivery service highlights
- 2-column "How it works" section with step-by-step flow
- Meal showcase gallery with appetizing images
- City and restaurant coverage section
- Customer review testimonials
- Subscription plan cards
- Contact form for sign-up or inquiries
- Smooth scrolling and subtle animation effects
- Responsive layout for desktop and mobile screens

## Tech Stack

- HTML5
- CSS3
- JavaScript
- jQuery
- AOS (Animate On Scroll)
- Ionicons
- Google Fonts

## Responsive Breakpoints Used

The layout is optimized using the following media-query breakpoints:

- 1200px and below: adjustments for large tablets and smaller desktop layouts
- 1023px and below: tablet-specific spacing, typography, and card layout refinements
- 767px and below: mobile/tablet transition rules for stacked sections and nav adjustments
- 480px and below: small phone optimizations for tighter spacing and form width
